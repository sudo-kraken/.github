# Security Policy

Please report vulnerabilities through GitHub's private
[security advisory form](../../security/advisories/new).
If private vulnerability reporting is unavailable, email
[sudo-kraken@prxy.8shield.net](mailto:sudo-kraken@prxy.8shield.net).

Do not disclose security vulnerabilities in public issues, discussions, or pull requests.
Include reproduction steps, the affected revision, impact, and any suggested mitigation when possible.
